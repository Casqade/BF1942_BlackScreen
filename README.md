This is a reimplementation of BlackScreen.exe from BF1942.

When compiled with Visual C++ 7.0 (Visual C++ .NET 2002, cl version 13.00.9466), 
the resulting binary is almost identical to the original one:
the biggest mismatch is in the loop at the end.
